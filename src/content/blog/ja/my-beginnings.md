## 幼少期

子供の頃、私は自分の決断や欲求を、子供にとって何が正しいかという論理に基づいて正当化するのが好きでした。また、たくさんの数のおもちゃを持っていて、妹と一緒に様々なテーマを織り交ぜた物語をたくさん作っていました。いつも遊んでいて、次の筋書きを用意することに励んでいましたが、時々折り紙をしたり、色々なキャラクターの紙人形を描いたりもしていました。

私の最初の試練は、自分の考えを自分の胸の内に秘めておくことでした。父と妹は女の子のことでからかうのが好きだったので、次元を分け隔てて、すべてを自分の力で解決しなければならなかったのです。

やがて両親の間で何度も喧嘩が起き、ついには裁判まで発展し、父は一緒に住むのをやめました。そのような変化を乗り越える私の方法は、「子供には遊ぶのが仕事だ」と自分に言い聞かせることでした。

ノートパソコンでは、何でもダウンロードさせてはもらえなかったので、Friv のようなブラウザゲームで過ごすことが多くありました。唯一の例外は Minecraft で、これがゲームをダウンロードして買う習慣の始まりです。また、あらゆるスタイルでプレイしている人の YouTube 動画を見て、タイトルを体験したり、新しいシナリオを発見したりしていました。特に惹かれたのは RPG でした。資源を管理しながら進めることができ、そこで私は、最良の報酬を得るために「待つ」ことを覚えたのです。

## 私の小さな泡

翌年の半ばごろ、父に家を出させられました。私と妹は近くの地区にある父方の叔母の家で暮らすようになったのですが、父はあちこちで働いていたので、一緒に暮らすことはありませんでした。よくやっていたのは、中心街への散歩です。海岸に近かったので、寒い風を感じないように、袖をまくったチャッカを着るようになりました。年の終わりには、今度は首都の叔母の家へ引っ越しました。そこには顔見知りでない叔父たちも何人か住んでいました。

両親の争いが原因で転校することになりましたが、授業中まで遊んでしまう性分だったので、転校自体はもっと前から経験していました。後になって女先生たちから、他の子供たちより物事の理解が早いから、遊ぶのは退屈しのぎなのだと聞かされたのです。

タブレットの使用を制限されたので、自分なりの遊びを作りました。紙人形、ボールペン、セロテープで。_ドラゴンボール_のアイデアや、学校の仲間たちの影響を受けていた。そこで「Luis」と「Fuego」を融合させたニックネーム「Fuis18」（Fu + is）を生み出したのです。

母の日を迎える頃、2つ目の試練が訪れた。自分のアイデンティティを守ること。私はあの2人の親の子であり、別の家族に養われているからといって、自分を偽ったり、合わせて振る舞ったりしなければならない道理はありません。年の終わりには、卒業旅行として2日間のキャンプに行き、妹と父も参加したので、自分の核家族と友人たちの間で時間をどう分けるかを考え始めました。

## 青春期へ

翌年、再び父方の叔母の家で暮らすようになりました。町は小さかったので、友達を作るのは楽でした。実際、今もそのうち一人とは連絡を取っています。その頃、私は歴史が苦手だという考えを抱くようになりました。ノートに書き写しながら日付や人名を暗記させることを求められばかりで、登場人物の文脈のための余白がほとんどなく、世界を進化させた出来事と結びつけることなく、ただ制限してばかりいたからです。

男になるか、子供のままに留まるかの間で、私は2つの場面に直面しました。1つ目は、父方の叔母の息子の娘（泣いていました）と議論したとき。いくつかの質問で問題を解決することができました。2つ目は、その叔母の夫に関するもの。電話が鳴ると、彼は「今さら誰が電話してくるんだ？」と言い、その妻は「何か用があるんだろうね、挨拶するためじゃないわよ」と答えました。その瞬間、私は「自分はただ挨拶するためだけに電話をかけるだろう」と決めたのです。それがやがて、極まるほどの習慣へと育っていきました。

年の半ばに2つの出来事が起こりました。まず、遠足でもらった小さなノートと小冊子に、気に入っている曲の名前を書き留め始めました。前年にたくさんの曲を知ったので、将来思い出すために、どこへ行くにもそれを持ち歩いたのです。インターネットがなかったので、限られた時間に「暗い日々」に備えて音楽をダウンロードしていました。

最後に、周囲の社会的圧力もあって、恋愛を意識して同級生にどう近づけるかを考え始めました。アドバイスのおかげで、彼女に手紙を書き始めました。身の回りの話や気になった出来事が、少しずつ人生の助言へと変わっていったのです。

## 「安定」？

中等教育を終えると、より安定した仕事を手に入れた父が迎えに来て、一緒に住むことになりました。何か起こるのを予感していたように、かつて取り上げられた紙人形を叔母に返してもらいました。

新しい土地に着くと、父は私たちに聖書を精読し、考えることを教えました。学問的な知識よりも批判的思考を育てるほうがよいと父は言ったからです。健康であろうとする気持ちも強まりました。それは論理的に正しいことだったからです。最後の試練はお金でした。間接的ではあるのですが、気ままな浪費より、貯めることや規模の経済を活かすことを優先するようになったのです。将来の楽しみのほうが割に合うから。まさにビデオゲームのようですが、現実の生活に適用したわけです。

学校に再入学すると、最初は無口なふりをして、少しずつ自分を開いていくやり方を適用しました。もうやり方は知っていたからです。ただ、今度はレベルが上がりました。この学校は教会そのものでもあり、向かいのアパートを借りて住んでいたのです。加えて、父は先生たちの友人でしたが、牧師は昔、父の弟子の一人でした。父は家庭問題で離れるまで、同じ組織を長く率いていたのです。だからこそ、次元を分けるのはずっと難しくなりました。

また、中心街を散歩するようになりました。常にチャッカで出かけるのは変だと感じられたので、寒い風をしのぎつつ熱中症にならないように、綿のシャツを着るのを勧められました。今では私のアイデンティティの一部であり、あらゆる状況で器用に振る舞えるようにしてくれています。

友達はたくさんでき、初めて SNS を持つようになりました（以前に携帯は持っていましたが、必要性は感じていませんでした）。覚えているのは、最初の行動の一つが気候変動への意識を高める動画を共有したこと。正しい取り組みに値する話題で、小さな一歩が大切だからです。

思春期になり、恋愛的な関係を求めたい気持ちもあったので、ノートを持って人を観察し、計画や動き、スケジュールを練るようになりました。教会を深く知り、ポップカルチャーにも飛び込みました。パソコンが苦手な同僚を助けたい一心で、その子にはメモ帳で HTML を教えていたので、私はブログや無料のコースで構文を学びながら、最初のウェブページを作り始めました。目標は、自分でウェブページを作って、インターネットを再現することでした。

## 立ち止まらないぞ！

翌年の入学手続きが終わり、ついに彼らと会い続けられると勘違いして喜んでいたのですが、そこへパンデミックが来ました。引っ越さなかったものの、会えなくなり、気力は落ちました。何にでも夢中になろうと探し始めたのです。SNS でつながろうとしても、安定したインターネットがなかったので、困窮の日のためにまたコースを探していました。ちょうどその時、YouTuber の @soydalto が HTML と CSS の動画を公開し、少しずつ進めていったのです。

さらに、名探偵のような能力が目覚めました。SNS は人を知る金鉱でした。どこにでも目を配れるなら、ですが。社会的には執着的に見えるかもしれませんが、テクノロジー分野では強力な推進剤になります。

長続きはしませんでした。年の半ばに引っ越したからです。国立の学校へ編入し、すべてがオンラインになりました。この新しい土地は別の県にあり、父の友人たちの家でした。素数や黄金比のような数学的なグラフを描き始めました。インターネットがある時は Roblox をして、オンラインで人と出会いました。分かち合うのは経験です。すごい依存になりましたが、頭を無理やりゲームに留めることも、退屈すると決めることもできるのだと理解しました。

## 帰還

翌年の初め、首都に戻って親戚と新年を過ごすことになりましたが、その一人が COVID-19 にかかっていました。父も感染し、私の誕生日の10日前に亡くなったのです。

まず第一に、何が起きているのか分かりませんでした。あの人たちと別れなければならない状況が続いていたので、頭は死そのものを消化できず、ただの引っ越しと同じように処理してしまったのです。そのまま自分の世界に閉じこもっていましたが、翌年にその積もった感情が決壊しました。

ニュースが広まると、母が迎えに来て、また引っ越しました。今度は幼年期を過ごした町です。長く両親と離れていたせいか、家族の感覚を失ってしまいました。代わりに、大きな情緒的独立を手に入れました。もちろん、後になって良い思いはしませんでした。

オンライン授業は続いたので、携帯を買ってもらい、姉が Guardian Tales を共有してくれたおかげで Delasama と出会いました。また、育った教会に通うようになり、いくつかの顔に心当たりを覚えながら、父のことを尋ねました。

年の終わりにパソコンを買ってもらいました。再び Wi-Fi がなかったので、自分のウェブページ作りを続けたい一心で、YouTuber の @soydalto が何時間もの JavaScript 講座を上げていたのを活用しました。そこで自動化の楽しさと、何より論理を使うことの味を知りました。しばらくの間、それは私のアイデンティティの柱になりました。他の誰かが解決に辿り着けるなら、自分の力で私がなぜできないのか。

そして、2つの大事な出来事もありました。

1. 教会のキャンプに行って、システムやお金に関係なく他人を助けたいと思っている女の子に出会いました。世界が広がり、ああいう人がいるのに驚きました。SNS で話を続けましたが、やがて連絡は途絶えました
2. サレジオ会の神父に出会い、年の終わりには良き友人になりました。彼と一緒に本格的に哲学を学び、死という問題も解いてもらいました。要するに、恨みや反感が残っていたとしても、その人を愛していれば、最も良い瞬間を通して思い出すことができる、ということです

## レベルを上げよう

学校の時代は、環境を次々に変えながら終えました。それが私をコンピューティングの熱心な愛好家にし、私の原則も進化させてくれたのです。そろそろ本格的に形にする時だと感じました。

あの女の子に会いに行くのが目標だったので、教会の青少年リーダーになる道を選びました。サレジオ会の神父は私の考えが気に入ったと言っていたほどです。ところが、経済面と責任の面で問題が起きました。

ソフトウェアエンジニアとして学費を払うために通信会社のコールセンターで働き始めたところ、同僚の数人が貯金会（pandero）に誘ってくれました。その間、YouTuber の @fazt のおかげで React とその様々なライブラリの勉強を始めました。目標は翌年の旅行用に貯金をすることでしたが、調整と信頼の面でトラブルが多かったのです。たくさんの人に出会いましたが、多くの人と別れざるを得ませんでした。頭は「ロボット化する」という一面を磨き始めていました。怒っているような人を短時間に何人も対応しなければならないからです。解決策が私に依らないことも多くても、何かを売り続けることを思い出さなければならず、脳は限界まで追い込まれました。2年間壊れながら、単位の取得、ライブラリの勉強、ミニストリーのプロジェクト、職場のめまぐるしい社会生活の管理を同時に進めていたのです。

買ってもらったノートパソコンは RAM が 4GB しかなかったので、システムの限界に触れ始めました。バックエンド（NestJS）、フロントエンド（NextJS）、データベース（PostgreSQL）を同時に立ち上げようとすると、とても遅くなったのです。そこで Linux 上にサーバーを立て、Docker を使って父のパソコンと自分のパソコンの間で負荷を分散することにしました。そして、もっとも軽量で、低スペックのパソコンに最適な Arch Linux を選んだのです。

コールセンターの時代が終わったので、Arch Linux を極める時間を得られ、こうして Rust の性能と、その後フリーソフトウェアのエコシステムを知ったのです。小さな必要性が頂点に達した時、カフェを助けるために、Web と Rust の知識を組み合わせて Tauri で最初のアプリを作り、その大きなポテンシャルを体験し始めました。

## 頂点

あの女の子に再会しようと、いくつかの手がかりをたどり、故郷を離れ、新しいシステムという構想を始めるための準備をすべて整えて叔母のところへ旅立ちました。わずかなお金で彼女を見つけることはできましたが、うまくはいかず、母も帰ってほしいと言ったので、これからはすべて自分一人で築いていかなければならないと思い、帰ることにしました。

1年間社会的に活動せず、完全に集中することに決めました。ところが、幼少期から私たちに寄り添ってくれていた叔父が亡くなりました。家族がみんな故郷の町に集まりましたが、積もった悲しみで心を閉ざしていた私は、死に対して涙も明らかな悲しみも見せなかったので、彼らの目に好印象を与えられませんでした。

## 最後に

時間をかけて考えを磨けるようになり、YouTuber の @midudev の動画を見るようになりました。エコシステムを広げ、原則を固め、自分自身を理解し始めました。年の半ば、Tauri のビルドがとても重く、扇風機を修理しなければならなくなりました。そこで準備を整え、メインのパソコンに Arch Linux をインストールし、PollyMC-Continued というプロジェクトにも出会いました。より積極的に活動し、性能と現代性の視点から知識を伝えられるように取り組んでいます。
